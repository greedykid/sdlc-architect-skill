# Execution Protocol Index

Use this index to load only the execution guidance needed for the current task. The previous combined protocol is intentionally split so state, iteration, evidence, commands, migrations, and forward testing can evolve independently.

- Read [project-state.md](project-state.md) when continuing across sessions or creating `docs/sdlc/project-state.md`.
- Read [iteration.md](iteration.md) when selecting, splitting, blocking, or closing backlog work.
- Read [evidence.md](evidence.md) when assessing confidence or interviewing for missing requirements.
- Read [commands.md](commands.md) when discovering or running build, test, migration, or deployment commands.
- Read [migration.md](migration.md) when changing persisted data, public contracts, or independently deployed services.
- Read [forward-testing.md](forward-testing.md) when evaluating the skill with behavioral scenarios.

Always preserve the repository's existing conventions. These references define the minimum decision and evidence standard, not a mandatory folder layout.
